# Nexo Abasto — Los Manguitos

Sistema de gestión de inventario, ventas, pedidos, transferencias y seguimiento operativo para *Los Manguitos*.

## Cómo abrir y ver la página con Open Live Server

1. Abre la carpeta del proyecto (nexo-abasto) en *Visual Studio Code*.
2. Asegúrate de tener instalada la extensión *Live Server* (de Ritwick Dey).
3. Abre el archivo index.html.
4. Haz clic derecho sobre el código (o en la pestaña del archivo) y selecciona *Open with Live Server*.
5. Tu navegador se abrirá automáticamente con la aplicación cargada en un servidor local.

## Qué verás en la interfaz

- *Barra superior de navegación:* permite cambiar entre las vistas de *Productos e inventario, **Bodegas y sucursales, **Clientes y ventas, **Pedidos y despacho, **Logística y rutas* y *Seguimiento*.
- *Panel de detalle:* al seleccionar un producto o ubicación, muestra su información, estado y movimientos recientes.
